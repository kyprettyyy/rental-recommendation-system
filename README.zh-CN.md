# 租房推荐系统

根据毕业设计文件夹整理的租房推荐工程，包含前端、Spring Boot 后端、Spark Streaming 推荐服务、数据库结构与历史实验笔记。

## 实际找到的流程

用户浏览房源 → 后端将行为写入 MongoDB，并发送至 Kafka → Spark Streaming 结合 MySQL 房源属性和历史行为计算 TF-IDF 相似度 → 推荐结果写入 Redis → 前端从后端读取列表。

| 模块 | 所选内容 |
| --- | --- |
| 后端 | `HouseProjectBackend-改`，保留房源筛选、行为采集、收藏、用户接口 |
| 推荐计算 | `HouseProject`，实际为 Spark Streaming 内容推荐 |
| 前端 | `项目5 - 副本`，包含与后端接口对应的页面 |
| 数据 | 仅提取表结构，补全收藏表，另附三条虚构示例房源 |
| 参考 | 爬虫源码、清洗笔记、尚未完成的协同过滤实验 |

原始 SQL 的用户、密码和房源数据未上传；数据库密码和主机地址已改为环境变量配置；去除构建输出、缓存、重复版本及不相关商城／教学代码。原始文件夹保留不变。

## 简历对应情况

Kafka、Redis、MongoDB 及行为驱动推荐有直接代码依据。现有推荐实现是 TF-IDF 内容推荐，不能将未完成笔记写成已接入的协同过滤；Flink 样例与租房主流程无关。未发现“新用户匹配效率提高 20%”的对照实验、指标定义或计时记录，因此没有编造实验数据。详见 [内容核对](docs/RESUME_MAPPING.md)。

## 运行与验证

完整步骤见 [运行说明](docs/RUNNING.md)。需要 JDK 8、Maven、MySQL、MongoDB、Redis、Kafka。前端随后端打包，可访问 `http://127.0.0.1:8080/index.html`。

当前机器没有 JDK/Maven，Docker 服务也未启动。已完成静态检查，另配置 GitHub Actions 编译验证；不声称已在本地跑通全部服务。历史登录和权限控制较弱，仅用于本地虚构数据演示。文件筛选、修复与测试边界见 [整理记录](docs/SOURCE_REVIEW.md)。
